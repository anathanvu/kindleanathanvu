3 Nâng cấp quan trọng vừa được xử lý từ ảnh thực tế trên Kindle của bạn

1. Chuẩn hóa Giờ Việt Nam (GMT+7)

Trình duyệt của Kindle chạy múi giờ gốc UTC+0 (nên 10:40 sáng bị lùi 7 tiếng thành 03:40). Bản mới đã khóa cứng thuật toán UTC+7 để luôn khớp từng phút với đồng hồ Kindle.

2. Xóa lỗi Font & Màn hình chờ

Đã loại bỏ hoàn toàn các ký tự Emoji gây lỗi ô vuông ▯, tách riêng font số và font chữ tiếng Việt, đồng thời ẩn hẳn lưới bên dưới khi mở Khung Ảnh Gia Đình.

3. Chạy thẳng file .sh không cần KUAL/MRPI

Sau khi chạy Sanctuary, máy đã tích hợp sẵn SH_Integration: bạn chỉ cần bấm nút Chống Khóa Màn Hình ở trên, tải file AnathanVu_Dashboard.sh chép thẳng vào thư mục documents của Kindle là xong!

Tải File Sách Lệnh (.SH): Chống Khóa 24/7 + Ẩn Thanh Trình Duyệt Fullscreen

Máy đã có sách "JAILBROKEN" — Không cần bấm Update Your Kindle!

Công cụ Sanctuary (bản mới jb.sh) khi tạo ra cuốn sách JAILBROKEN là đã tự động cài sẵn Hotfix, kích hoạt sẵn bộ chạy file .sh và khóa luôn mục Update Your Kindle (để chặn Amazon tự cập nhật máy). Vì vậy bạn không cần cài file .bin hay tìm nút Update Your Kindle nữa!

Chỉ cần chép thẳng 2 file sách lệnh (.SH) vào thư mục documents của Kindle:
  1. Bấm 2 nút dưới đây để tải 2 file .sh về máy tính.
  2. Cắm cáp USB nối Kindle vào máy tính (nếu trước đó bạn có chép file Update_hotfix_universal.bin vào ổ Kindle thì hãy xóa nó đi), sau đó mở thư mục documents (Kindle/documents/).
  3. Chép cả 2 file AnathanVu_Dashboard_24_7.sh và AnathanVu_Tat_Chong_Khoa.sh thả thẳng vào thư mục documents.
  4. Rút cáp USB ra:
    • Chạm vào sách "1. BAT Dashboard AnathanVu (Full Screen + Pin That 24/7)" trên màn hình Library để mở Dashboard tràn viền 100%, tự xoay ngang, đồng bộ % pin thực tế và không bao giờ tắt màn hình.
    • Khi muốn đọc sách lại bình thường, chạm vào sách "2. TAT Dashboard (Khoi Phuc Man Hinh Goc)".
